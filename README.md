# Cloudflare Browser Lab

Public, disposable browser/runtime specimens compiled from private engineering work.

This repository contains **execution artifacts only**. Canonical reasoning, private operational doctrine, credentials, and private project state do not belong here.

## First specimen

`cake-welcome/` is a dependency-free HTML/CSS/JS interaction test:
- preserves the host page background
- renders a cake-shaped button
- click emits confetti
- "Welcome!" scrolls across the viewport
- reduced-motion behavior is supported

Cloudflare is intended to use this repository as a preview/test deployment source.
